16-Week First 50K Plan

Built for jobs, families, and imperfect weeks.

A Plan You Can Actually Finish

This is a first-50K framework for people who cannot live in a training app all day. It emphasizes time on feet, easy aerobic work, recovery weeks, and practicing fueling — the stuff that matters more than fancy workouts when race one is about finishing. If you are still unsure you are ready, start with the readiness checklist.

Who this is for

  • You can already run easy for about 90 minutes and recover.
  • You can train ~4 days most weeks (3 running days minimum in a crunch).
  • Your goal is finishing a 50K, not podium fantasies.

Rules when life explodes: Never skip recovery weeks to “make up” miles. If you miss midweek, keep the long run when you can. If you miss the long run, do not stack a monster week next — resume the schedule. Consistency beats hero days.

Weekly shape (most weeks)

  • 1 long run (weekend) — the priority session.
  • 2–3 easy runs midweek — conversational pace.
  • Optional strength 1×/week (20–30 min): glutes, calves, single-leg balance. Not bodybuilding.
  • 1+ full rest day.

The 16 weeks

Times are targets, not police. Terrain: match your race as much as you can. On hills, hiking is training, not cheating.

Fueling inside the plan

From week 5 on, treat the long run like race day: eat early, eat often. Details in Fueling 101. Do not debut a new gel brand on race morning.

FAQ

Can I run by miles instead of time?

Yes. Convert using your easy pace. Time-on-feet is the better coach for trails and hiking sections.

What if I only have 3 days some weeks?

Keep the long run + two easy runs. Cut strength first, then a midweek run — not the long run.

Do I need speedwork?

For race one, strides and a little steady work are enough. Save big interval blocks for later cycles.
